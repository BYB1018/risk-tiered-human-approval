# Risk-Tiered Human Approval

## 中文

按动作的外部影响与可逆性决定 AI 自动化边界：研究和草拟通常可自动；外发、付款、删除、生产变更等动作需要展示影响并等待明确批准。

适用于 Agent、获客、求职自动化和生产操作；不会替用户扩大授权。

## English

Set automation boundaries according to external impact and reversibility. Research and drafting can usually be automated; sending, paying, deleting, or changing production requires showing the impact and waiting for explicit approval.

Use it for Agents, outreach, job-search automation, and production operations. It does not expand the user's authorization.
